# EnglishSav

Learn American English from A1 to C2 with Persian support: an English–Persian dictionary, phrasal verbs, idioms, grammar, graded reading, public-domain books, pronunciation practice, a placement test, and an optional AI tutor.

یادگیری انگلیسی آمریکایی از A1 تا C2 با پشتیبانی فارسی.

## Download

Get the latest `EnglishSav-<version>-universal.apk` from **Releases**.

- Android 7.0 or newer.
- Open the APK on your phone and allow "Install unknown apps" for your browser or file manager when Android asks.
- Updates install over the old version and keep your progress, as long as they come from this page.

## Check that your download is genuine

Every official build is signed with the same key. Before installing, you can check:

**APK SHA-256** (changes every release; listed in each release's notes):
```
0bf325ff453373dff8e0120bf4a386002d5f2c1f5b6bf5995edb4bd40322d9e4  EnglishSav-5.3.8-universal.apk
```

**Signing certificate SHA-256** (never changes):
```
63:8A:61:E0:DD:95:4C:7A:1D:BF:5A:57:62:E7:C0:05:D2:D0:91:91:9A:46:B1:B4:35:C8:66:41:48:6F:3F:9A
```
Check with: `apksigner verify --print-certs EnglishSav-5.3.8-universal.apk`

If either value doesn't match, don't install the file. Only download EnglishSav from this page.

## Permissions

- Internet and network state: optional account, sync, AI tutor, voice downloads.
- Microphone: only when you use speaking or pronunciation practice.
- Notifications and start at boot: only for the daily study reminder you turn on.

## Privacy and terms

The app works offline without an account. See [PRIVACY.md](PRIVACY.md) and [TERMS.md](TERMS.md), also in the app under Settings, then About.

To delete your account: in the app, Profile, then Delete account. If you can't open the app, open an issue here titled "Delete my account" with your username (don't post your password).
